산출물: 같은 화면의 대안 시안 3개를 `prototypes/` 아래 HTML 로 — 브라우저에서 바로 열리고, {폭: 예 390px 모바일 / 1280px 데스크톱}.
셋은 **이 화면을 서로 다르게 읽는다**(개념·구성이 다르다). 각 파일 맨 위 HTML 주석에 「이 시안이 이 화면을 무엇으로 읽었나」 한 줄.
색은 기존 토큰 파일을 `<link>` 나 `:root` 변수로 쓴다(값을 손으로 베끼지 않는다).

끝내기 전에: 각 시안을 실제 폭으로 열어 **스크린숏을 찍어 직접 본다** — 글자 잘림·겹침·가려짐, 도형 어긋남, 빈 자리 표시가 없게.
결과로 돌려줄 것: 만든 파일 셋과, 각 시안이 무엇을 보여 주려 했는지 한 줄씩.
