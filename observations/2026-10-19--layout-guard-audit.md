# 배치 무결성 게이트 감사 — 「흐르는 띠」 가리개가 심한 잘림을 면제하고 있었다

  ② 가리개 교정 전후 검출 집합을 **같은 폭(390px)에서 차집합**으로 비교

## ① [측정] 양성 대조군이 가리개의 문턱에 0.6% 차로 걸려 있었다

```
.narrow { width: 90px; overflow: hidden; white-space: nowrap }   /* 양성 ③ */
  scrollWidth 163 / clientWidth 90  →  비율 1.811
가리개:  const ticker = a.scrollWidth > a.clientWidth * 1.8      /* 1.8 배 = 흐르는 띠 */
```

가리개는 2026-10-12 `0.2.9` 에서 seemilar 섀도 런의 **흐르는 로고 띠 오탐**을 막으려고 넣었다.
그 지표는 **폭 하나**였고, 그래서 양성 ③ 과 구별되지 않는다 — 측정값이 `1.811`,
문턱이 `1.800`, 간격 **0.6%** 다.

**[측정] 지표의 방향이 거꾸로다.** 잘림은 심해질수록 비율이 커진다.
즉 **심한 잘림일수록 면제된다.** 가벼운 잘림(연도 칩 — `0.2.9` 가 실제로 잡은 것)은
비율이 작아 통과했고, 그래서 가리개가 한 주 넘게 살아남았다.

## ② [측정] 같은 가리개가 우리 산출물의 실제 잘림 2건도 면제하고 있었다

교정 전후 차집합 (`products/` 9개 · 390px · 중복 제거):

| | 검출 |
|---|---|
| 교정 전 | 22건 |
| 교정 후 | **24건** (+2) |

새로 나온 2건은 `taste-probe-5.html` · `taste-probe-6.html` 의
`span.forcelab "밝은 테마 고정"` 이다. 실측 체인:

```
span.forcelab 줄 상자  →  조상 button.opt { overflow: hidden }
  button.opt  scrollWidth/clientWidth = 1.829   ← 1.8 을 넘겨 「띠」 로 면제됐다
  줄 상자가 그 상자의 좌우 경계를 넘는다 = 실제로 잘려 있다
```

**1.811(대조군)과 1.829(실제 산출물)가 2% 안에 있다.** 독립된 두 사건이 같은 자리에서
잡히지 않았다 — 문턱값이 우연히 나쁜 것이 아니라 **지표가 틀렸다.**

그 잘린 것이 무엇인지가 덧붙는다 — `밝은 테마 고정` 은 **W42 가 신설한 `force` 표시**,
즉 「이 판정이 어느 테마에서 나왔는가」를 사람에게 알리는 라벨이다.
측정 조건을 적어 두는 라벨이 좁은 폭에서 잘려 있었다.

## ③ [측정] 가장 비싼 것 — 측정 직전에 **움직임을 지운다**

띠를 띠로 만드는 것은 폭이 아니라 애니메이션이다. 그래서 가리개를
`animationName !== 'none'` 으로 바꿨더니 **그래도 띠가 걸렸다.**

```
measure-render.mjs:  await page.addStyleTag({ content: '*{animation:none!important}' })   // 안정화
```

재는 시점의 계산된 스타일에는 **애니메이션이 하나도 없다.** 안정화를 위해
우리가 직접 껐기 때문이다. 즉 **재는 환경이 판별 근거를 먼저 지웠다.**
`M3`(주석이 검사를 통과시킨 것)와 같은 모양의 사건이다 —
검사가 보는 것과 검사가 묻는 것이 다른 자리에 있었다.

교정: 끄기 **전에** 움직이는 요소에 표시를 찍고(`data-dd-moving`), 가리개는 그 표시를 읽는다.
가리개는 이제 **폭 1.8배 그리고 움직임**을 함께 요구한다.
(폭 조건을 남긴 이유: `animation` 은 페이드인 등으로 흔해서, 움직임만으로 가리면 면제가 너무 넓어진다.)

## ④ [측정] 가리개에는 음성 대조군이 **없었다**

`0.2.9` 가 가리개를 넣을 때 근거는 seemilar 섀도 런의 실데이터였고,
그 꼴은 **레포에 남지 않았다**(`git log -S ticker` · 전 마크다운 검색 — 한 줄 언급뿐).
그래서 가리개는 「양성 대조군이 음성과 같은 급으로 필요하다」의 **반대 사례**였다 —
음성만 믿고 양성을 재지 않은 것이 아니라, **음성 대조군 없이 가리개를 넣었다.**

- **[추론·미확정]** seemilar 의 띠는 CSS 애니메이션으로 흐르는 로고 줄이었을 것이다.
  그 꼴을 `tests/fixtures/layout.html` 에 되살려 음성 대조군으로 고정했다.
  **원본을 확인하지 못했다** — 섀도 런 산출물이 레포 밖이다.
  JS(`scrollLeft`)로 흐르는 띠였다면 교정된 가리개는 그것을 가리지 못한다.
  다음 섀도 런에서 1회 재확인한다.

## ⑤ [측정] 영수증이 거짓을 적고 있었다 — 대상이 주지 않은 드라이버

같은 검사에서 둘이 더 나왔다. `measure-render` 의 playwright 탐색 ① 은
`createRequire(<대상>/package.json).resolve()` 로 **대상이 고정한 버전**을 쓴다고 적혀 있다.

```
대상: /home/user/design/tests   (playwright 없음 · node_modules 없음)
실제 해석: /opt/node-tools/node_modules/playwright     ← 기계 전역
영수증에 적힌 것: "playwright @ tests"                 ← 거짓
```

node 의 해석은 상위 폴더와 전역 폴더까지 거슬러 올라간다. 대상 **안**에서 나온 것이
아니면 「대상이 고정한 버전」이 아니다. 교정: 나온 자리를 적는다 — `(대상 밖)`.

그리고 이것이 테스트 2건을 가리고 있었다 — 「브라우저 없으면 미측정으로 통과」와
「미측정은 영수증을 남기지 않는다」는 **전역 설치가 있는 기계에서 조건을 만들 수 없다.**
한 건은 두 기계에서 다 성립하는 더 강한 단정으로 바꿨고(대상이 주지 않은 것을
줬다고 적지 않는다), 나머지는 **소리를 내고 건너뛴다**(`⏭` — 통과로 세지 않는다).

## ⑥ 우리 규칙과 충돌하는 지점

1. **「실데이터로 걸러낸 오탐」이 양성 대조군보다 센 근거로 취급됐다.**
   `0.2.9` 의 오탐 다섯은 전부 실데이터였고, 그래서 가리개가 양성 대조군을
   끌 때 아무도 묻지 않았다. 실데이터는 **그 사례**를 증명하지, 지표를 증명하지 않는다.
2. **안정화와 측정이 같은 페이지에서 일어난다.** 재기 위해 끄는 것이 있으면
   끄기 전에 찍어야 한다. 이번은 애니메이션이었고, 같은 꼴이 더 있을 수 있다
   (`transition` · `scroll-behavior` · `prefers-reduced-motion` 에뮬레이션).
3. **탈출구(가리개)에는 음성 대조군을 요구하는 규칙이 없다.** 검출기에는 있다(`tests/`).
   면제에는 이유를 요구하지만(`D-21`), **가리개에는 대조군을 요구하지 않는다.**
