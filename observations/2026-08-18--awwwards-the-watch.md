## L1 기하
- **반경 0종.** border-radius를 아예 쓰지 않는다
- HTML이 3.5KB — 화면 대부분이 캔버스/WebGL로 생성됨

## L2 타이포 ★
- 서체 2종: Inter(36회) + Nekst(28회). 그로테스크 2종 조합
- **font-size가 vw 단위이고 소수점 10자리**: `.0694444444vw`, `.1302083333vw`, `.3125vw`, `.8333333333vw`
  → 브레이크포인트 계단 없이 뷰포트에 완전 비례하는 유동 타이포
- px 리터럴은 11px 하나뿐

## L3 색
- **hex 1종** (`#ebebeb`). 나머지 색은 전부 WebGL 런타임 생성으로 추정
- CSS 정적 파싱으로는 색 관계를 측정할 수 없는 케이스 → 이 사이트는 L3 미측정으로 남긴다

## L4 표면·깊이
- 그림자 0종. 깊이를 CSS가 아니라 3D 렌더로 만든다

## L5 모션
- CSS 듀레이션 1종(1.2s) + ease-in-out. **CSS는 모션의 주역이 아니다**
- 실제 모션은 WebGL 루프 → 정적 CSS 파싱의 측정 한계 지점

## L6 구조·IA
- (registry 정책상 이 소스에서 L6 미신뢰. 미기록)

## L8 판정
- **신선함**: 반경 0 + 그림자 0. "둥근 모서리와 그림자로 만드는 위계"를 통째로 포기하고 3D로 대체
- **포화**: 없음
- **이식 최소단위**: vw 기반 완전 유동 타이포 — 브레이크포인트 없이 비례만으로 스케일
- **트레이드오프 쌍** ★
  - 얻은 것: 모든 뷰포트에서 레이아웃 비례가 정확히 보존됨. 브레이크포인트 유지보수 비용 0
  - 포기한 것: **사용자 글꼴 크기 설정을 무시한다.** vw는 브라우저/OS 확대 설정에 반응하지 않아
    저시력 사용자가 본문을 키울 수 없다. 또 초대형·초소형 뷰포트에서 통제 불가
  - → **불변항 Ⅰ-1(접근성)과 정면 충돌.** 이 결정은 우리 산출물에 그대로 이식 불가
