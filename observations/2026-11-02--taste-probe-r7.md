## 3. [추론] 기본값에 대해 무엇을 말하나

- 장치가 넣던 처방은 「한글 = 음수, 클수록 더 음수」 다. 측정이 말하는 것은 **본문은 0 을 고른다 · 큰 제목은 구분하지 않는다** 이다.
  두 결과 어디에도 「음수」 를 고른 판정이 없다(네 판정 중 음수 0건)
- 범위보류는 「양수일 수도 있다」 는 뜻이지 「음수일 수도 있다」 가 아니다. 한글 본문을 넓히는 것은 처방 후보에 없었으므로
  **실무적 질문(좁히나 마나)에는 답이 났다 — 좁히지 않는다.**
- 같은 방향의 근거가 이미 셋 있다 — ① `graphic` 포스터 제목 자간 0 확정(`g02`/`g15`/`S5`, 음수 범위·양수 범위가 0 에서 만났다)
  ② 외부 반례 3건 · 제작사 3곳(웨스틴 본문 0 · 서울디자인페스티벌 44~48px 굵은 제목 0 · 29CM 0) ③ W45 재관측 7곳 중 「크기가 클수록 더 음수」 지지 0곳.
  이번 회차는 그 셋에 **사용자 눈**을 더한다
- 한계: marketing 바탕 하나 · 본문 15px · 제목 30px 하나씩만 쟀다. `tool`·`consumer` 의 작은 글자(12~13px)와 48px 이상 대형 제목은 재지 않았다

## 4. [측정] 바탕의 결함 — 큰 제목이 「세 / 번의 저녁」 으로 끊겼다

K01 의 「왜」 첫 문장은 자간이 아니라 **제목 줄바꿈**을 말한다. 렌더로 확인했다(Chromium, `~/.design-device/runtime` playwright):

| 화면 폭 | 카드 폭 | 큰 제목 줄바꿈 (네 변형 공통) |
|---|---|---|
| 1440 · 1000px | 191px (4열) | 겨울밤 / 실내악, 세 / **번의 저녁** |
| 800px | 168px (4열) | 겨울밤 / 실내악, 세 / 번의 저녁 |
| 620px | 272px (2열) | 겨울밤 실내악, / 세 번의 저녁 |
| 390px | 157px (2열) | 겨울밤 / 실내악, 세 / 번의 저녁 |

- 데스크톱 폭에서 네 변형 **전부** 「세」 가 앞 줄에 남았다 — `keep-all` 은 어절을 지키지만 **의미 덩어리(「세 번의 저녁」)는 지키지 않는다**
- 자간 값과 무관하게 같은 자리에서 끊겼으므로 **큰 제목 문항의 변수는 오염되지 않았다.** 다만 30px 제목이 191px 칸에 세 줄로 들어가
  −0.01 ~ −0.04em(글자당 0.3 ~ 1.2px) 차이가 원래도 작은 데다 더 보이지 않았을 수 있다 — 「차이 없음」 의 일부는 이 좁은 칸 탓일 수 있다
- 덤: 본문 −0.04em 변형만 첫 문단이 6줄 → 5줄로 줄었다(191px 칸). 사용자는 그 변형을 고르지 않았다

대안으로 든 문장 *"겨울 밤 저녁, 여러분들을 기다립니다"* — 숫자 대신 **초대하는 말**이다.

측정 축이 아니라 사용자의 말이므로 집계에 넣지 않고 이벤트 톤 카드 후보로 상신한다.
