# 관측 분해 스키마 (Taxonomy)

레퍼런스를 "느낌"으로 저장하면 스크랩이고, **파라미터로 분해**해야 자산이다.
분해된 항목만 조합·반박·폐기·이식이 가능하다.

## 절대 규칙

1. **값이 아니라 관계로 기록한다.** `#6366F1`이 아니라 `배경 대비 4.8:1, 중립축에서 색상거리 240°, 채도 상위 15%`. 값은 복제를 낳고 관계는 이식을 낳는다.
2. **모든 항목은 날짜와 출처를 갖는다.** 트렌드는 사실이 아니라 시점 증거다.
3. **분해할 수 없으면 기록하지 않는다.** "고급스럽다" 같은 항목은 L1~L7 중 어디로 환원되는지 쓰지 못하면 버린다.
4. **관측(observation)은 규칙이 아니다.** 규칙이 되려면 `signals/`로 승격돼야 하고, 승격 조건은 독립된 2개 이상 출처 + `invariants.md` 통과다.

## 레이어

### L0 — 메타
- 출처 URL / 캡처일 / 관측 라운드 ID
- 제품 카테고리 (SaaS, 커머스, 핀테크, 툴, 미디어, …)
- 플랫폼 (web-responsive / iOS / Android / landing / wireframe-IA)
- 시장·언어권 (한국어 조판은 라틴 조판과 다른 제약을 가진다 — 별도 기록)

### L1 — 기하 (Geometry)
- 베이스 유닛 (4/8/기타) 과 실제 준수율
- 스페이싱 **리듬**: 위계 간 여백 점프 비율 (예: 8 → 16 → 40, 배수가 아니라 곡선)
- 그리드: 컬럼 수, 거터 비율, 최대 폭, 콘텐츠 폭 대 뷰포트 비
- 라운드 **로직**: 요소 크기 대비 반경 함수인가, 고정값인가, 중첩 시 보정하는가
- 브레이크포인트 **행동**: 단순 축소인가, 레이아웃 재배치인가, 요소 탈락인가

### L2 — 타이포
- 램프 비율 (1.125 / 1.2 / 1.25 / 불규칙) 과 단계 수
- 폰트 분류 조합 (그로테스크/휴머니스트/세리프/모노) 와 **대비 전략** — 대비가 크기뿐인가, 서체·굵기·폭도 쓰는가
- 리딩/트래킹이 크기에 따라 어떻게 변하는가 (상수면 감점 신호)
- 최적 줄길이 준수 여부 (45~75ch)
- 한글 조판: 자간 처리, 줄바꿈 규칙, 라틴 혼용 시 베이스라인 보정

### L3 — 색
- **역할 구조**: 중립 단계 수, 액센트 개수, 시맨틱(성공/경고/위험) 분리 여부
- 배경 대비 전경 대비비 (본문 / 보조 / 비활성 각각)
- 액센트의 색상거리·채도 위치 — 중립축과 몇 도 떨어져 있고 채도 분포 어디인가
- 다크모드 전략: 반전인가, 재설계인가 (채도 조정 / 엘리베이션 재정의 여부)
- 색이 정보를 나르는가, 장식인가

### L4 — 표면·깊이
- 엘리베이션 모델: 그림자 / 보더 / 배경 명도차 / 채도차 중 무엇으로 층을 나누는가
- 실제 층 개수 (2층이면 위계 없음, 5층 이상이면 과설계)
- 그림자 스펙 (블러·스프레드·불투명도·색상 — 검정 알파인가 색조 있는가)
- 반투명·블러 사용 시 가독성 보정 여부

### L5 — 모션
- 커브 (ease-out / spring / custom cubic) 와 **용도별 분화** 여부
- 듀레이션 밴드 (마이크로 / 전환 / 진입 각각) — 단일값이면 감점 신호
- 트리거 (스크롤 / 호버 / 상태변경 / 진입) 와 스태거 유무
- `prefers-reduced-motion` 대응
- 모션이 상태 변화를 설명하는가, 데코인가

### L6 — 구조·IA
- 레이아웃 아키타입 (셸+사이드바 / 캔버스 / 피드 / 위저드 / 단일컬럼 …)
- 네비게이션 패턴과 깊이, 현재 위치 표시 방식
- 정보 밀도 (화면당 유의미 단위 수) 와 밀도 조절 장치 유무
- 진입/온보딩 플로우 단계 수와 이탈 지점
- 빈 상태 / 로딩 / 에러의 설계 여부 (없으면 명시적으로 "없음" 기록 — 흔한 결함)

### L7 — 톤·이미지
- 카피 밀도 (요소당 단어 수) 와 보이스
- 이미지 전략 (사진 / 일러스트 / 3D / 스크린샷 / 없음) 과 일관성
- 아이콘 시스템 (스트로크 굵기, 광학 크기, 의미 부여 여부)
- 브랜드 표현이 색·타입·모션 중 어디에 실려 있는가

### L8 — 판정
관측마다 반드시 넷을 남긴다.
- **신선함**: 지금 시점에 흔하지 않은 지점은 정확히 무엇인가 (레이어 지정)
- **포화**: 이미 흔해진 지점은 무엇인가 → `anti-patterns.md` 후보
- **이식 최소단위**: 이 사이트를 베끼지 않고 가져올 수 있는 가장 작은 결정은 무엇인가
- **트레이드오프 쌍**: 그 결정으로 **무엇을 얻고 무엇을 포기했는가**

> **결과가 아니라 결정을 기록한다.**
> "이 히어로가 멋있다" → 결과. 베끼는 것 말고 할 게 없다.
> "제목을 본문의 4.2배로 키우는 대신 굵기 대비를 포기했다" → 결정. 어떤 장르에든 이식된다.
>
> 트레이드오프 쌍이 비어 있으면 그건 결정이 아니라 취향이다. **승격시키지 않는다.**
> 이 항목 하나가 소스의 장르 편향을 상당 부분 무력화한다 — 포스터에서 나온 조판 결정도,
> 마케팅 사이트에서 나온 모션 결정도, 트레이드오프로 적히는 순간 모드를 건너뛴다.

### L9 — 적용 가능 모드
이 관측이 어느 모드에 적용될 수 있는가 (`tool` / `consumer` / `marketing` / `graphic` 중 복수 가능).
`invariants.md` Ⅱ 참조. 소스별 기본 채택 레이어는 `sources/registry.yaml`.

## 파일 형식

`observations/YYYY-MM-DD--<source-slug>.md` 하나에 L0~L9.
`signals/<slug>.md` 는 승격된 신호만: 근거 관측 링크 2개 이상, 최초 관측일, 반감기 가중치,
적용 조건, **`falsified_by:`** (승인 `#22 A`).

`falsified_by:` 는 **반증이 없을 때도 빈 칸으로 둔다.** 칸이 없으면 반증이 기록될 자리가 없고,
자리가 없으면 철회가 추적되지 않는다 — 신호는 조용히 살아남고 반례는 대화 속에서 사라진다.
한 줄에 **무엇이 · 언제 · 어디서** 를 적는다: `2026-10-11 · 관측 r4b · 0단계 vs 1단계를 물어 축이 무효`.
